## 价格口径

美国 Apple / Amazon 页面通常展示税前价格，所以页面提供 0–10% 的销售税滑块。

香港没有销售税；中国大陆与香港的页面标价直接按当地结账标价比较。

“公开优惠”不包含以旧换新、二手、翻新和无法稳定复核的短时券。

“包含资格优惠”会纳入已核实的教育商店起价，因此不代表所有人都能购买。
