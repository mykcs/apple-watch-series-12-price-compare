## 核心规格事实

两者都使用 S11 芯片和蓝宝石玻璃表镜，核心健康与智能功能相同。

陶瓷更重，并且 Apple 明确强调其表壳抗刮：

- 42mm 钛金属：36.5g
- 42mm 陶瓷：41.7g（珍珠白）/ 42.8g（夜蓝）
- 46mm 钛金属：44.9g
- 46mm 陶瓷：51.3g（珍珠白）/ 52.9g（夜蓝）
