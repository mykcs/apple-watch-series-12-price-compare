Mac 芯片怎么选

不是把“核心越多越好、内存越大越好”重新说一遍。这里把芯片升级拆成几种真正不同的资源：CPU 并行、GPU 规模、内存带宽、可用内存档位、媒体引擎和 I/O。你可以看到每次加钱到底买到了什么。

“芯片大小”怎么理解

Apple 没有公布这些芯片的官方物理面积（mm²）。M5 Pro / Max 还使用两颗晶粒组成的 Fusion Architecture，所以本页不伪造一个“芯片有多大”的数字，而用会直接影响工作的资源规模来表示。

不同工作，看的是不同东西

大型编译 / CPU 并行

先看 CPU 核心和持续功耗。M5 Pro 18 核以后，Max 的 CPU 核心数并没有继续增加。

本地 LLM / 大数据工作集

模型先要装得进内存，再看内存带宽。对这类工作，307→460→614GB/s 比“芯片名字”更直接。

3D / Metal / AI 图像

GPU 核心数和内存带宽一起重要。20→32→40 核 GPU 才是 Pro 到 Max 最明显的资源扩张。

视频

M5 与 M5 Pro 都是一组视频编码 / ProRes 引擎；M5 Max 直接变成两组。多路 ProRes 才更容易吃到这个升级。

高速外设

MacBook Pro M5 是 Thunderbolt 4；M5 Pro / Max 是 Thunderbolt 5。Mac mini 也是 M6 用 TB4、M5 Pro 用 TB5。

外接显示器

MacBook Pro：M5 最多 2 台、Pro 3 台、Max 4 台。Mac mini 两个芯片家族都能到 3 台，但接口带宽不同。
